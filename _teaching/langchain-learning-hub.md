## Learning Philosophy

This course emphasizes **clarity over novelty** and **execution model awareness**. Instead of chasing surface-level trends, it focuses on developing durable understanding that compounds across adjacent domains.

### Key Principles

- **Clarity over novelty** – Fewer concepts, deeply understood
- **Execution model awareness** – Understanding how tokens flow and chains compose
- **Naming things precisely** – Distinguishing core abstractions accurately
- **Progressive generalization** – Start concrete, then abstract
- **Reusability and evaluation** – Treat every component as a testable unit

## Curriculum Structure

### Part 1: Fundamentals
- **Lesson 1**: Introduction to Generative AI
- **Lesson 2**: The Six Core Components of LangChain
- **Lesson 3**: LangChain Components & Setup
- **Lesson 4**: Models & Prompt Foundations
- **Lesson 5**: LangChain Model Component Deep Dive

### Part 2: Retrieval (RAG) Systems
- Loaders, splitters, embeddings
- Vector stores and retrievers
- End-to-end RAG implementation

### Part 3: Agents & Advanced Patterns
- Tools and tool calling
- Structured reasoning
- Agent assembly and orchestration

### Capstone Project
Multi-tenant, production-aligned RAG system integrating all learned concepts.
